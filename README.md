# 界络祈愿 · V1.1版本

这是一个无需安装软件或下载依赖的网页抽卡项目。网页文件、图片和启动脚本全部位于当前文件夹。

本次发布名称为 **V1.1版本**，版本标签为 `V1.1`。具体内容见 [CHANGELOG.md](CHANGELOG.md)。本版仍为校园测试版，数据保存在当前浏览器。

## 如何打开

**最简单：**双击 `index.html`，用 Edge、Chrome 或 Firefox 打开即可使用。

**本地网址方式：**双击 `启动界络祈愿.cmd`，保留弹出的运行窗口，再在浏览器打开 **http://127.0.0.1:4173/**。关闭运行窗口即停止服务。该服务只允许本机访问，不提供学校局域网共享。

这两种方式的浏览器存档互相独立，请固定使用其中一种。推荐固定使用本地网址方式；无需联网。

## 如何测试

1. 填写任课老师、班级、学生姓名，点击“保存信息”。新档案赠送 100 次抽卡机会。
2. 点击左侧卡池，点击“祈愿 1 次”或“祈愿 10 次”。弹窗显示新卡、重复转化及保底 SSR。
3. 页面显示当前卡池、全部卡池累计抽数、该卡池 SSR 保底剩余抽数。
4. 重复卡自动变为能量碎片，拥有至少 10 枚时点击兑换按钮。每次消耗 10 枚，获得 1 次机会。
5. 在“我的卡牌”“祈愿记录”之间切换查看结果。刷新网页，档案和进度应保留。
6. 修改学生信息后先保存再抽卡。再次输入完全相同的老师、班级和学生姓名会恢复已有档案。

## 测试版规则

| 卡池 | 角色 |
| --- | --- |
| 英语 | R：狸谱、布蕾兹；SR：书签卡 01、02、03；SSR：仅布蕾兹 |
| 数学 | R：乐游、狸谱；SR：仅狸谱；SSR：仅乐游 |
| 语文 | R：狸谱、李岩；SR：仅狸谱；SSR：仅李岩 |
| 限定活动 | 狸谱、布蕾兹、乐游、李岩 |

- 本期英语池的 R 为狸谱、布蕾兹，SR 为三款独立书签卡，SSR 只会出现布蕾兹。数学池 R 为乐游、狸谱，SR 只出狸谱，SSR 只出乐游。语文池 R 为狸谱、李岩，SR 只出狸谱，SSR 只出李岩。限定活动池全部四位角色均有 R、SR、SSR 三种卡；同卡池、同稀有度内的可用卡牌等概率出现。
- 基础概率：R 90%、SR 8%、SSR 2%。可在 `engine.js` 中调整。
- 每个卡池独立计算 80 抽 SSR 大保底。连续 79 抽未出 SSR，第 80 抽必为 SSR；任意 SSR 均重置对应卡池的进度。
- 切换卡池不丢失进度。十连也是按抽取顺序逐次计算，没有额外的 SR 保底。
- 同一档案在全部卡池共用收藏。角色卡按同角色、同稀有度判定重复；书签按同款编号判定重复，不区分角色。书签 01、02、03 可各自入库。
- 重复 R / SR 转化 1 枚碎片；重复 SSR 转化 2 枚；每 10 枚兑换 1 次机会。兑换不增加抽数，也不改变保底进度。
- 三项身份信息共同区分档案；姓名前后的空格会被去除。班级写法不同会被视为不同档案。
- 单抽需至少 1 次机会，十连需至少 10 次；不足时对应按钮不可用。

可以直接用正式 SVG 图片替换同名文件。如果使用 PNG、JPG 或 WebP，请把图片放在同一目录，再修改 `engine.js` 顶部对应角色的 `image` 路径，例如 `assets/characters/lipu.png`。推荐竖版 480 × 680 像素。

只替换某个稀有度时，可在该角色的 `rarityImages` 中配置对应路径，例如 `rarityImages: { SSR: 'assets/characters/blaze-ssr.jpg' }`。图片替换不会修改概率、保底或已有存档。

如果一个稀有度有多张卡面，将 `SSR` 配置为图片路径数组即可。卡面随机选择独立于稀有度和角色随机选择。

## 存档和使用范围

存档位于当前浏览器的本地存储，键名为 `jieluo-wish-v1`，不写入项目文件、不上传服务器。保留最近 200 抽记录，但累计次数、保底、机会、收藏和碎片完整保留。

本测试版适合在一台电脑上体验规则。它没有学生登录、教师授权、后台发放机会和跨设备同步；学生信息是档案标识。正式全校使用需要增加服务端与身份验证。

不要清理浏览器数据，除非确实想删除全部档案。如果提示存档损坏，先在浏览器开发者工具的“应用/存储 → 本地存储”中备份 `jieluo-wish-v1` 的内容，再删除该键并刷新，可重新开始测试。存储禁用或空间不足时，页面会拒绝操作，避免显示未保存的抽卡进度。

在多个窗口同时打开时，其他窗口修改存档后，本窗口会提示刷新再继续，以避免覆盖。

## 文件说明

- `index.html`：首页，双击可运行。
- `styles.css`：深蓝星空界面与手机适配。
- `engine.js`：抽卡、保底、重复卡与兑换规则。
- `app.js`：页面交互、学生档案与本地保存。
- `server.ps1`：Windows 自带 PowerShell 即可运行的本机网页服务。
- `启动界络祈愿.cmd`：一键启动本机服务。
- `tests/`：开发时使用的规则和浏览器检查，不影响正常运行。

修改文件后刷新网页即可，不需要编译。
